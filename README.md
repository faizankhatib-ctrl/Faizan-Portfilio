# Faizan Khatib — Portfolio Website

> Modern, responsive developer portfolio and research showcase built with React and Vite, featuring a Bento Grid layout and custom dark Navy/Amber aesthetic.

![Portfolio Preview](/public/pexels-tara-winstead-8386440.jpg)

## 🚀 About

Faizan Khatib is a Full Stack Developer (MERN Stack, Java) and published researcher (JATIR 2026). This portfolio showcases software engineering internships, featured projects, published research on technology and mental health, and technical skill sets.

## ✨ Features

- **Unique Bento Grid Layout**: Organized, responsive cards inspired by modern design standards.
- **Custom Color Palette**: Deep Navy (`#0B2545`), Midnight (`#13315C`), Slate (`#4F6D9A`), and Amber (`#E9B44C`) with ambient glows.
- **Hero Visual Showcase**: AI & neural network visual card with floating status badges and interactive hover effects.
- **Scroll Reveal Animations**: Smooth scroll reveals powered by `IntersectionObserver`.
- **Experience Timeline**: Detailed career timeline covering internships at ITView, Vier Labs, and Codveda.
- **Featured Projects**: Full Stack applications with repository links and tech stack tags.
- **Publications Section**: Featured peer-reviewed research paper published in JATIR (Vol. 2, Issue 6).
- **Centralized Icon System**: Clean, reusable SVG icon component without external icon bloat.
- **Fully Responsive**: Optimized across mobile, tablet, and widescreen desktop displays.

## 🛠️ Tech Stack

- **Frontend**: React 19, JavaScript (ES6+)
- **Build Tool**: Vite 8
- **Styling**: Vanilla CSS (Custom Design System, CSS Variables, Flexbox/Grid)
- **Fonts**: Fraunces & Inter (Google Fonts)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/faizankhatib-ctrl/Faizan-Portfilio.git
   cd Faizan-Portfilio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
```
Production assets will be output to the `dist/` directory.
